# Roadmap

1. **Foundation — complete:** inspect existing Vue app and initial prompt; write SPA migration plan; capture visual baselines.
2. **Design system — complete:** retain approved CSS, fonts, SVG and WebP assets without coordinate changes.
3. **Shared components — complete:** header, hero, services/card, form, SVG UI and backdrop extraction.
4. **SPA navigation — complete:** typed nested routes, lazy details/form, reactive titles, direct links and 404.
5. **Motion/tooling — complete:** VueUse Motion confirmation, Bun lockfile, DevTools inspect mode, lint/format, CI.
6. **QA — complete:** unit/component tests, build/typecheck, 11-width geometry regression, real history/refresh/focus tests and desktop/mobile screenshot comparison.
7. **Future, not implemented:** real enquiry endpoint, CMS/API adapters if required; original brand vector files if supplied. No dashboard/auth/payments are scheduled by this migration.
