# Project overview

Schoolino is the repository name; the approved delivered brand is Avin. The current objective is a frontend-only, Persian RTL service landing page for training, AI/R&D and IT infrastructure. The latest task applies the engineering stack from initial_prompt.md without changing the approved visual design.

Audience: individuals seeking training/career growth and organizations exploring AI/IT services. Primary actions: explore services, open a detail route, and complete a clearly marked demonstration enquiry form. No actual lead delivery, login, checkout, student dashboards or learning platform modules are in this scope.

Success: same approved UI, reusable Vue components, direct URLs/history, strict types, stable assets, reproducible Bun installation and passing quality checks.
